# IronLog mejorado

Versión más modular para GitHub Pages y iPhone.

## Qué cambia
- La parte visual queda separada en archivos más pequeños.
- Las acciones se dividen por bloques.
- Se mantiene el comportamiento general de la app.

## Estructura
- `index.html`
- `entreno.html`
- `ejercicios.html`
- `progreso.html`
- `logros.html`
- `configuracion.html`

## Uso
Sube todo a la raíz de GitHub Pages y abre la web en Safari. Después usa **Compartir → Añadir a pantalla de inicio**.
